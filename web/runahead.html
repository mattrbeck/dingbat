Run-ahead A/B — same input to both cores

Pick a ROM to load it into both panes.
Baselineordinary loop_tick
Run-aheadrunahead_tick(2)

Keyboard drives both panes at once (keep focus on this page — don't click inside a pane): arrows = D-pad, Z A, X B, Enter Start, Backspace Select, A/S L/R. The amber bars flash while any game button is held — film the screen in slo-mo and count frames from flash to on-screen response in each pane. Audio starts muted in both panes; unmute one via its overlay. Changing the frame count reloads the right pane (re-pick the ROM after).
